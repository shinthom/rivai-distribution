0.0.1-dev

dev
Build ID: 2026.05.17.001 Released: 2026-05-17

Test Focus

이번 빌드는 배포 파이프라인 자체를 검증하기 위한 더미 빌드입니다. 게임 콘텐츠는 포함되어 있지 않습니다.

  • 홈페이지에서 자기 OS에 맞는 다운로드 버튼이 강조되는지
  • 다운로드한 zip의 sha256이 manifest 값과 일치하는지 (수동 검증)
  • Mac: 압축 해제 후 Rivai.app 번들 구조가 유지되는지
  • Windows: 압축 해제 후 Version.txt에 적힌 Version·Build ID가 이 패치노트와 일치하는지

Changes

  • 최초 dev 채널 배포
  • Windows·Mac 더미 클라이언트 zip 동시 제공
  • manifest 단일 파일로 두 플랫폼 빌드 관리 (client.win64, client.mac)
  • R2 public bucket을 통한 무결성 검증(sha256) 가능한 배포 파이프라인 가동

Fixes

최초 빌드 — 해당 없음.

Known Issues at Release

최신 미해결 이슈는 Known Issues 페이지를 참고하세요. 배포 시점 기준 핵심 항목:

  • 클라이언트가 더미라 실행해도 게임이 동작하지 않음 (M0.2 / D01 이후 실제 빌드로 교체 예정)
  • 런처 없음 — 수동 zip 다운로드만 가능 (D01 완료 시 자동 다운로드·검증 제공)
  • Mac은 사인되지 않아 첫 실행 시 Gatekeeper가 막음 (우클릭 → 열기로 우회)
