등록: 2026-05-17 발견 빌드: 0.0.1-dev 영향: 전체

우회 없음. M0.2 / D01 이후 실제 Unreal 빌드로 교체될 예정입니다.

런처 없음 — 수동 다운로드만 가능

등록: 2026-05-17 발견 빌드: 0.0.1-dev 영향: 전체

현 단계에서는 홈페이지에서 zip을 직접 받아야 합니다. 자동 다운로드·sha256 검증·실행은 런처(D01)에서 제공됩니다.

홈페이지의 Download 버튼을 사용. 받은 zip의 sha256을 manifest와 직접 비교하면 무결성 확인 가능.

Mac: Gatekeeper가 첫 실행을 차단

등록: 2026-05-17 갱신: 2026-05-18 발견 빌드: 0.0.1-dev 영향: macOS 사용자

코드 사인되지 않은 클라이언트와 런처는 macOS Gatekeeper가 첫 실행을 막습니다. macOS 버전에 따라 우회 방법이 다릅니다.

macOS 14 (Sonoma) 이하: Finder에서 Rivai.app / Rivai Launcher.app을 우클릭 → "열기" 선택 → 경고창에서 "열기" 클릭. 한 번 허용된 뒤로는 더블클릭으로 열립니다.

macOS 15 (Sequoia) / 26 이상: 정책이 강화되어 위 방법이 동작하지 않고 "손상되었기 때문에 열 수 없습니다"로 표시됩니다. 실제로 손상된 것이 아니라 macOS가 사인되지 않은 다운로드 파일에 자동으로 붙이는 quarantine 속성 때문입니다. 터미널에서 다음 명령으로 quarantine을 제거하세요.

xattr -dr com.apple.quarantine ~/Downloads/Rivai\ Launcher.app

또는 명령 일부만 친 뒤 Finder의 .app 파일을 터미널 창에 드래그하면 경로가 자동 입력됩니다. 클라이언트 zip을 손으로 받은 경우에도 동일하게 압축 해제 후 .app 또는 .exe 경로에 적용하세요.

정식 코드 사인 + 공증(notarization)은 Apple Developer 계정($99/년)이 필요해 후속 마일스톤에서 처리합니다.
