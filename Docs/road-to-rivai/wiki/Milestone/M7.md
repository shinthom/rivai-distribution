# M7: GunZ-style Tech & Multiplayer Game Alpha

## 목표

M6의 안정화된 멀티 게임 루프 위에 **GunZ와 같은 메커니즘을 활용한 고속 이동·캔슬·무기 리듬**을 구현한다. M7 완료 시 목표는 상용 서비스가 아니라, 팀 내부와 제한 테스터가 GunZ-style 테크닉으로 Duel / Small Room을 반복 플레이할 수 있는 Alpha 상태다.

## 선행 조건

- [ ] M6 Playable Loop 완료
- [ ] 2~8인 Dedicated 라운드 테스트 가능
- [ ] 100ms 환경의 이동·전투 보정 로그 기준선 존재
- [ ] Cancel Rule Table 또는 동등한 데이터 기반 규칙 존재
- [ ] Slash / Block / Swap / Shot Placeholder가 서버 권위로 동작

## 핵심 산출물

- GunZ-style Technique Set v1
- Animation Cancel Rule Table
- Weapon Rhythm / Delay Model
- Reload Cancel / Swap Cancel 규칙
- Butterfly / Slashshot / Half Step / Wall Cancel
- Shotgun 또는 Ranged Weapon v1
- Duel Map v1, Movement Combat Course
- Tech Debug HUD와 입력 리플레이 로그

## 포함 범위

| 기능 | 완료 기준 |
|---|---|
| Butterfly | Jump → Dash → Slash → Block이 서버 권위 상태로 재현 |
| Slashshot | Jump / Dash / Slash / Swap / Shot 연결 가능 |
| Half Step | 2회 Dash 리듬과 Shot 타이밍이 일관 |
| Reload Shot | Reload가 Shot delay / Swap rhythm에 미치는 규칙 정의 |
| Wall Cancel | Wall Jump 후 Slash / Dash 재진입 루프 가능 |
| Weapon Rhythm | Shot delay, Swap delay, Reload cancel window 데이터화 |
| Advanced HUD | 현재 Technique, 입력 버퍼, Cancel 가능 여부 표시 |
| Multiplayer Alpha | 2~8인 Duel / Small Room에서 테크닉 기반 전투 가능 |

## 제외 범위

Public Alpha 운영, 정식 매치메이킹, 랭킹, 상점, 스킨, 대규모 맵 풀, 완성형 튜토리얼, 상용 안티치트, 전체 무기 밸런스 완성.

## Technique Set v1

```text
Core:
- Butterfly      : Jump -> Dash -> Slash -> Block
- Slashshot      : Jump -> Dash -> Slash -> SwapToGun -> Shot
- Half Step      : Jump -> Dash -> Slash -> SwapToGun -> Dash -> Shot
- Reload Shot    : Shot -> Reload -> Swap -> Shot
- Wall Cancel    : WallJump -> Slash -> DashToWall

Optional if stable:
- Double Butterfly
- Flash Step
- Reload Half Step
```

## 입력·캔슬 원칙

- 입력은 Enhanced Input 기준으로 기록하고, 서버 검증에 필요한 최소 값만 전송
- Cancel Window는 프레임 감각으로 튜닝하되 서버 시간 기준으로 판정
- 애니메이션 Notify는 연출 동기화에 사용하고, 피해·캔슬 확정의 단일 근거로 쓰지 않음
- Weapon Swap / Reload / Shot delay는 데이터화해 빌드마다 비교 가능하게 유지
- 원작의 글리치 감각을 그대로 방치하지 않고, 의도된 규칙으로 재현한다

## 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 원작 글리치를 규칙화하지 못함 | Technique별 입력·상태·캔슬 표를 먼저 확정 |
| Cancel Window가 너무 관대해 무한 루프 발생 | Cancel Rule Table에 chain limit / cooldown 포함 |
| Animation과 판정이 어긋남 | 서버 시간 Active Window와 연출 Notify를 분리 |
| Shot / Reload / Swap이 네트워크에서 불안정 | Weapon Rhythm을 서버 권위 상태로 관리 |
| 고급 테크닉이 초보 테스트를 막음 | Movement Combat Course와 기본 Duel 룰을 함께 제공 |
