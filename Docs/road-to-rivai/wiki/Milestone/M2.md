# M2: Air Movement

## 목표

M1 지상 이동 위에 **Air Dash**와 **Wall Detection**을 더한다. Wall Run 완성이 아니라, 벽 이동 조건을 안정적으로 판정하고 서버가 검증할 수 있게 만드는 단계.

## 선행 조건

- [ ] M1 Ground Dash 완료
- [ ] Debug HUD에 State/Velocity/Ping 표시
- [ ] Movement Gym 반복 테스트 가능
- [ ] 2인 서버 접속 테스트 가능

## 핵심 산출물

- Air Dash
- Wall Detection Trace (Surface·Angle 필터)
- Wall Candidate State
- Movement State Machine 확장
- HUD에 Wall Normal·Surface·Distance
- 서버 검증 가능한 공중 이동 입력

## 포함 범위

| 기능 | 완료 기준 |
|---|---|
| Air Dash | 횟수·리셋 조건 명확 |
| Wall Detection | HUD에 Normal·Distance·Angle 표시 |
| Surface Filter | 잘못된 표면에 붙지 않음 |
| State Machine | Ground/Air/WallCandidate 분리, 로그 확인 |
| Server Validation | 비정상 입력 거부 |

## 제외 범위

Wall Run/Jump 완성, Slash/Block, Weapon Swap, 복잡한 콤보, 외부 플레이테스트.

## Wall Detection 설계

**감지 방향:** Forward / Left / Right (+ Optional Diagonal) Capsule Trace.

**판정 데이터:** Hit Actor, Component, Impact Point, Normal, Distance, Surface Type, Angle From Up, IsRunnableSurface.

**표면 필터**

```text
Valid:   wall-range angle, runnable surface, distance ≤ AttachMax,
         speed ≥ MinEntry, not grounded
Invalid: floor/ceiling, forbidden material, too far, in exit cooldown
```

## Air Dash 규칙

```text
CountMax: 1 | Reset: Grounded or WallJump
Cooldown: 0.25s | Duration: 0.12s | Speed: 1300~1800
Direction: Camera-relative input
Server Check: cooldown, count, velocity cap, movement mode
```

## 구현 방향

- Trace 결과를 무조건 신뢰하지 말고 서버 재검증
- Air Dash는 CMC 예측/보정 경로 내부에 배치
- 벽 감지는 Shape Trace / Capsule Sweep
- 각도·최소속도·진입·이탈 조건을 데이터 에셋/Config화
- Debug Draw 필수

## Debug HUD 예시

```text
Movement Mode: Falling | GZ State: AirDash
Air Dash Count: 0/1
Wall Candidate: true | Distance: 48.2 | Angle: 89.4
Wall Normal: (-0.98, 0.04, 0.01) | Runnable: true
Server Validated: true | Correction Count: 1
```
