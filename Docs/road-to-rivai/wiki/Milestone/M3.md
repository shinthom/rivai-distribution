# M3: Wall Movement

## 목표

M2 Wall Detection 위에 **Wall Run / Wall Jump / 이동 콤보**를 구현한다. GunZ-like 체감이 나타나기 시작해야 하지만, M3의 목표는 최종 밸런스가 아니라 서버 권위 구조에서의 성립 검증.

## 선행 조건

- [ ] M2 Air Dash 완료
- [ ] Wall Candidate 안정 감지
- [ ] 표면 필터 동작
- [ ] HUD에 Normal·Distance·Angle 표시

## 핵심 산출물

- Wall Run / Wall Jump
- Exit / Cooldown 규칙
- Dash → Wall → Jump → Air Dash 콤보
- Combo Debug HUD
- 서버 보정 로그
- Movement Gym Wall Course

## 포함 범위

| 기능 | 완료 기준 |
|---|---|
| Wall Run | 진입·유지·이탈 조건 일관 |
| Wall Jump | 방향·속도 편차 허용 범위 |
| Combo Chain | 정의된 콤보 재현 가능 |
| Server Correction | 보정 로그·HUD 표시 |
| Wall Course | 팀원이 동일 코스 테스트 가능 |

## 제외 범위

Slash/Block, Weapon Swap, 히트 판정, 정교한 캔슬, 랭크·매치메이킹, 안티치트.

## State 흐름

```text
Grounded ─ GroundDash / Jump
Airborne ─ AirDash / Falling / WallCandidate
WallCandidate ─ WallRun ─ WallJump / WallExit
```

## Wall Run 진입 조건

```text
- Airborne
- WallCandidate 존재
- Runnable surface
- Speed ≥ MinWallRunEntrySpeed
- Angle within allowed range
- Not in WallExitCooldown
- Server validates candidate surface
```

## Wall Jump 계산

```text
JumpDir = WallNormal * NormalForce
        + UpVector  * UpForce
        + InputDir  * InputInfluence
```

서버는 Wall Normal, Velocity, Cooldown, Surface Validity를 검증한다.

## 구현 방향

- Wall Run은 Custom Movement Mode로 분리 우선 검토
- 속도·중력 스케일·Normal·입력·지속시간 서버 검증
- Root Motion 중심 구현은 보정 난도 ↑ → Movement Component가 권위
- Trace 위치·표면 필터 표준화
- 캔슬 가능/불가 시간은 GameplayTag 또는 명확한 State Flag

## Wall Course 구성

```text
Straight Wall Lane | L/R Entry Zone | Jump Distance Markers
Air Dash Recovery | Combo Timing Gate | Server Correction Observation
```
