# M1: Movement Prototype

## 목표

GunZ-like movement의 기반을 다진다. M1의 핵심은 "재미있는 대시 완성"이 아니라 공중·벽 이동을 얹을 수 있는 **네트워크 가능한 이동 기반** 구축이다.

## 선행 조건

- [ ] M0.1 Manual Distribution 완료
- [ ] Build Version이 게임 화면에 표시
- [ ] 테스트 빌드 배포 가능
- [ ] 최소 1개 테스트 맵 실행 가능

## 핵심 산출물

- Movement Gym 맵
- C++ `AGZPlayerCharacter`, `UGZCharacterMovementComponent` 초안
- Ground Dash
- Debug HUD (Build/Server/Ping, 속도·가속도·마찰·입력)
- PIE / Standalone / Dedicated 테스트 프로파일

## 포함 범위

| 기능 | 완료 기준 |
|---|---|
| Movement Gym | 평지·거리 마커·속도 측정 구간 |
| Debug HUD | 스크린샷만으로 상태 파악 가능 |
| Ground Dash | 전·측·후방 대시가 규칙적으로 동작 |
| Movement State | Idle/Run/Dash/Fall 전이가 로그·HUD에 표시 |
| Network Skeleton | 대시 입력의 서버 검증 구조와 불일치 추적 |

## 제외 범위

Air Dash, Wall Detection/Run/Jump, Slash/Block, Weapon Swap, 정교한 애니메이션 캔슬, 상용 랙 보정.

## 구현 방향

```text
AGZPlayerCharacter
 ├─ UGZCharacterMovementComponent
 ├─ UGZMovementDebugComponent
 ├─ UCameraComponent
 └─ USpringArmComponent
```

**Ground Dash 원칙**
- CMC 확장 — Blueprint Tick의 `SetActorLocation` 금지
- 가능하면 custom flag 또는 SavedMove에 대시 입력 포함
- 서버가 Cooldown·Direction·MaxSpeed 검증
- 클라이언트 즉각 반응, 서버 보정 로그 수집

## Debug HUD 예시

```text
Build: 0.1.0-movement | Build ID: 2026.05.17.001
Server: test-01:7777 | Ping: 42ms
Movement Mode: Walking | GZ State: GroundDash
Velocity: 1250 | Acceleration: 840 | Dash Cooldown: 0.35
Correction Count: 0
```
