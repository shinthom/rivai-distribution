1/ Mac의 `.app`은 단일 파일이 아니다

Windows의 `.exe`와 달리, Mac의 `.app`은 마우스로 더블 클릭하면 실행되지만 실제로는 폴더다. 마우스 우클릭 후 '패키지 내용 보기'를 누르면 내부에 바이너리, 라이브러리, 리소스(`Info.plist` 등)가 가득 차 있는 디렉토리 구조임을 알 수 있다.

2/ 일반 zip 압축 시 Mac 앱이 깨지는 이유

macOS 파일 시스템은 실행 권한(Permission), 기호 심볼릭 링크(Symbolic Link), 확장 속성(Xattr) 등 눈에 보이지 않는 중요한 메타데이터를 포함한다. Windows 환경이나 일반 zip 도구로 압축하면 이 정보가 전부 유실되어, 압축을 풀었을 때 실행 파일이 일반 텍스트로 변하거나 권한 에러가 발생한다.

3/ `ditto` 명령어가 해결사인 이유

`ditto`는 macOS에 내장된 파일 복사 및 압축 전문 CLI 도구다. 일반 zip과 달리 Mac 특유의 리소스 포크(Resource Fork)와 권한 설정을 100% 보존하면서 압축 파일(`zip`)을 만들어 주기 때문에, Mac용 게임 빌드를 배포할 때는 무조건 이 명령어를 사용해야 한다.

4/ `ditto` 핵심 옵션 한 줄 요약

문서에 나온 `ditto -c -k --sequesterRsrc --keepParent` 옵션은 "Mac 특유의 메타데이터와 리소스를 격리하여 안전하게 포함하고(`--sequesterRsrc`), 부모 폴더 구조를 유지하면서(`--keepParent`) zip 아카이브를 생성한다"는 뜻이다. 파이프라인 자동화 시 필수 공식이다.
