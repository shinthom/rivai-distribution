문제 정의

우리가 풀어야 하는 두 가지 문제

DEVELOPER 측

"어떻게 전달하지?"

  • 500MB+ 게임을 매번 슬랙으로 보낼 수 없다
  • 패치마다 zip 압축 + 공유 = 시간 낭비
  • 서버는 누가 24시간 켜놓나?
  • 버전 관리는?

USER 측

"어떻게 즐기지?"

  • 받자마자 곧바로 플레이하고 싶다
  • 패치는 자동으로 됐으면
  • 친구가 어디에 있는지 모르겠다
  • Host? Join? IP? 모르겠고 그냥 Play하고 싶다

아키텍처 결정

왜 클라우드를 두 개 쓰나?

AWS — 게임 서버 전용

"항상 켜진 VM"

  • 실시간 UDP 트래픽을 받아야 함
  • 한국 팀원 RTT(지연시간) 최소화 → Seoul 리전
  • 고정 IP / 도메인이 필요
  • 24시간 죽지 않아야 함 (systemd)

CLOUDFLARE — 정적 자산 전부

"전 세계 CDN"

  • 500MB+ 게임 파일을 어디서나 빠르게
  • egress 비용 0 (R2의 핵심 장점)
  • 웹사이트도 같이 (Pages, Workers)
  • S3 호환 API → 멀티파트 업로드 가능

실시간 시뮬레이션과 대용량 파일 배포는 본질적으로 다른 일 — 분리가 자연스럽습니다.

내부 문서 전용

셋 다 wrangler 한 CLI로 배포 — 운영이 단순합니다.

STEP 1 / 3 — 사용자 흐름

포털 방문 → 런처 받기

사용자가 하는 일

  • 브라우저로 rivai-portal.pages.dev 방문
  • 운영체제에 맞는 다운로드 버튼 클릭
  • 런처 zip 다운로드 (약 5 MB)
  • 압축 풀고 실행

시스템이 하는 일

  • Pages가 정적 HTML 응답
  • 다운로드 링크는 R2 public URL
  • R2가 직접 zip 응답 (egress 무료)
  • 사용자 임의 위치에 설치 가능

여기까지가 사용자가 의식적으로 하는 유일한 다운로드입니다.

STEP 2 / 3 — 사용자 흐름

런처가 게임을 가져온다

  1. manifest 읽기R2의 manifest/dev.json
  2. 버전 비교내 버전 vs latestVersion
  3. 게임 zip 다운로드다른 경우에만
  4. SHA256 검증파일이 손상되지 않았는지
  5. 압축 해제 + 설치바로 실행 가능 상태로

manifest/dev.json (R2)

{ "latestVersion": "0.1.0-dev", "client": { "mac": { "downloadUrl": "…/rivai_client_0.1.0-dev_mac.zip", "sha256": "d81f111c…", "sizeBytes": 574274751 } }, "server": { "host": "13.125.11.128", "port": 7777 } }

★ manifest 한 줄 갱신 = 모든 사용자 자동 패치

STEP 3 / 3 — 사용자 흐름

Play 한 번 → 자동 서버 접속

# 런처가 게임을 실행할 때 $ open Rivai.app --args \ -ServerAddr=13.125.11.128:7777 \ -Nickname=alpha # 게임은 인자를 받자마자 서버에 connect GameInstance.Init → commandline 파싱 MainMenu Play button → "open 13.125.11.128:7777"

사용자 입장

Play 한 번

Host도 Join도 IP도 안 묻습니다. 닉네임만 입력하고 Play.

새 클라이언트 PostLogin

개발자 측 · 단 한 줄

한 번의 명령으로 5가지가 일어난다

$ ./release-game.sh \ --version 0.1.0-dev \ --build-id 2026.05.18.003 \ --channel dev \ --client-mac Rivai.app.zip
  1. SHA256 + 크기 계산파일 무결성과 진행률 표시용
  2. R2 업로드300 MiB↑ 자동 멀티파트 (wrangler → boto3 fallback)
  3. manifest 갱신버전 · SHA · 서버 정보 한 번에 (cache: 60s)
  4. 패치노트 렌더템플릿 → patch-notes/<ver>/index.html
  5. Pages 배포wrangler pages deploy → rivai-portal

멱등(idempotent) — 같은 명령을 다시 돌려도 안전합니다.
