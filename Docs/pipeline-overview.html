Runtime · How it works

The manifest is the single source of truth

  1. Launcher startsUser double-clicks the launcher icon
  2. Fetch manifestRead manifest/dev.json from R2
  3. Compare versions + downloadIf different: download game zip → verify SHA256 → unzip
  4. Click PlayPass server info from manifest as commandline args to the game
  5. Auto server connectGame reads args at startup → connects to AWS UDP 7777

manifest/dev.json (R2)

{ "latestVersion": "0.1.0-dev", "client": { "mac": { "downloadUrl": "…/rivai_client_0.1.0-dev_mac.zip", "sha256": "d81f111c…", "sizeBytes": 574274751 } }, "server": { "host": "13.125.11.128", "port": 7777 } }

★ One JSON line = every user's next action

Updates · Developer side

A release in one line

$ ./release-game.sh \ --version 0.1.1-dev \ --build-id 2026.05.20.001 \ --channel dev \ --client-mac Rivai.app.zip \ --notes notes.json
  1. Compute SHA256 + sizeFor integrity check and download progress UI
  2. Upload to R2Files over 300 MiB auto-fallback to boto3 multipart
  3. Update manifestChange latestVersion → every launcher picks it up on next run (60s cache)
  4. Render patch notesTemplate → patch-notes/<ver>/index.html + prepend index + update /latest/ redirect
  5. Redeploy Pageswrangler pages deploy → rivai-portal

Idempotent — re-running the same command is safe.
